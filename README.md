# 30Day_STM_Challenge🩰
30Day STM (Small Things Matter) Challenge is a 30 day build challenge focused on creating tine, complete software projects every day.
## STM Challenge — Days 01–10

| Day | Folder | Project | Description |
|---:|---|---|---|
| 01 | [`day01/`](./day01/) | CLI Todo | Add/list/complete tasks in the terminal. |
| 02 | [`day02/`](./day02/) | Number Guessing | Guess the random number with hints. |
| 03 | [`day03/`](./day03/) | Text Analyzer | Counts words/characters and basic stats from input text. |
| 04 | [`day04/`](./day04/) | Notes App | Save and view notes (file-based). |
| 05 | [`day05/`](./day05/) | URL Shortener (Local) | Shorten + expand URLs using a local JSON file. |
| 06 | [`day06/`](./day06/) | Daily Challenge Generator | Random “mini task” generator using a date-based seed. |
| 07 | [`day07/`](./day07/) | Quick Mini Tool | Small, easy utility (starter project). |
| 08 | [`day08/`](./day08/) | Easiest Creative Build | Minimal but creative script/tool. |
| 09 | [`day09/`](./day09/) | Anti-Doomscroll Redirect | Redirects you to a better activity when you feel like scrolling. |
| 10 | [`day10/`](./day10/) | Secret Folder Copier | Copies a chosen `.txt` into `~/secret_folder/` as `user_secret.txt`. |

> Goal: build one small thing per day, prioritize shipping over perfection.
